不知道怎么用

只需打开本应用，菜单栏 / 任务栏 / 桌面面板 中就会出现一个小图标，随后你就可以从本地的 DLNA 客户端把媒体文件投送到你的电脑上。

如何使用第三方播放器插件

  1. Macast 以往需要你自行下载的播放器——IINA、Web、Live、PotPlayer、PIFMRDS 以及 NVA 协议——现在已内置在应用中。它们列在插件标签页， 可在该页直接启用或停用。
  2. 若要添加自己的插件：在插件标签页安装一个 [某插件].py， 或将文件拖入打开配置目录下的 renderer / protocol 目录。
  3. 无需重启——插件安装后即生效。

如果找不到想要的插件，可前往 此处 了解如何编写自定义渲染器插件，欢迎提交 Pull Request。

DLNA 客户端找不到 Macast

  • 检查防火墙是否拦截了 Macast。
    一个简单的检测方法是：从其他设备访问 Macast 开放的端口（默认为 58880，可在设置菜单中查看）。
  • 检查路由器。
    应开启 UPnP 并关闭 AP 隔离（AP Isolation）。
  • 软件问题。
    若使用 iOS 设备，请确保对应 App 的 「本地网络」查找与连接权限已开启。
    部分应用需要等待 30 秒以上才能发现 Macast，请耐心等待。
  • UDP 组播问题。
    有反馈称 Windows 与部分路由器存在适配问题，导致 Windows 无法加入组播。此时需修改 Windows 注册表，强制将 IGMP 版本设为 v2。
  • 多网卡或复杂网络环境。
    请确保在单网卡、且与 DLNA 客户端处于同一局域网的条件下 Macast 可正常使用；更复杂场景的解决方案仍在完善中。

启动时崩溃

Macast 默认开放端口 58880。当你的电脑上该端口被占用时，应用会崩溃。请手动设置应用端口， 此后 Macast 会从配置文件中读取你指定的端口。

无法关闭或无响应

使用第三方播放器插件时，插件通常需要开启更多线程或进程，导致应用退出时出现无响应问题， 这通常是由插件本身引起的。

并将一些 mpv 命令行选项写入配置文件，例如：
